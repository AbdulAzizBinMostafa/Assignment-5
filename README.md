1. var is function-scoped and can be redeclared. let is block-scoped and can be reassigned but not redeclared in the same scope. const is also block-scoped but cannot be reassigned after initialization.

2.The spread operator expands elements of arrays, objects, or iterables into individual values. It is commonly used to copy arrays, merge arrays, or combine objects.

3. map() creates a new array by transforming each element. filter() creates a new array with elements that match a condition. forEach() simply runs a function for each element and returns nothing.

4.  An arrow function is a shorter syntax for writing functions in JavaScript using =>. It is commonly used for concise callbacks and does not have its own this context.

5.  Template literals are strings written with backticks (`) that allow embedding variables or expressions using ${} and support multi-line strings easily.
